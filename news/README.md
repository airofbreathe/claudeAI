# ☀️ 아침 뉴스

매일 아침 GitHub이 뉴스를 모아 웹페이지 한 장으로 만들어 줍니다.
휴대폰에서 그 페이지를 열기만 하면 돼요.

## 어떻게 움직이나요? (3단계)

1. **새벽 5:50, 6:50 (한국 시간)** — GitHub의 컴퓨터가 알람처럼 깨어나요.
2. `make_news.py`가 구글 뉴스에서 주요·경제·IT·세계·스포츠 뉴스를 가져와요.
3. 휴대폰에서 보기 좋은 웹페이지로 만들어 인터넷에 올려요 (GitHub Pages).

## 처음 한 번만 할 일

1. 이 코드를 `main` 브랜치에 합치기 (merge)
2. GitHub 저장소 → **Settings → Pages** → Source를 **GitHub Actions**로 바꾸기
3. **Actions** 탭 → "아침 뉴스 만들기" → **Run workflow** 눌러서 바로 한 번 만들기
4. 완료되면 주소가 생겨요: `https://<내아이디>.github.io/<저장소이름>/`

## 휴대폰에서 아침에 자동으로 열기

**아이폰** (단축어 앱)
- 단축어 → 자동화 → 새로운 자동화 → **알람** → "알람이 중단될 때" 선택
- 동작: **URL 열기** → 위의 뉴스 주소 → "즉시 실행" 켜기
- → 아침 알람을 끄면 뉴스가 바로 뜹니다!

**안드로이드 (삼성)**
- 설정 → 모드 및 루틴 → 루틴 → **+** → 조건: "알람이 해제되면" 
- 실행할 동작: 앱 → 인터넷 열기(주소 입력) 또는 아래 "홈 화면 추가" 아이콘 실행

**제일 쉬운 방법**: 브라우저에서 주소를 열고 **홈 화면에 추가** → 아이콘 하나 누르면 뉴스!

- 시간 바꾸기: `.github/workflows/morning-news.yml`의 `cron` (한국 시간 − 9시간)
